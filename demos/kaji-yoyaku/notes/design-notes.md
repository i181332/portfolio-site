# デザインの控え（frontend-design スキルでの見直し・批評ループのたびに上書き）

## 主題・読者・主な役割
- 主題：八王子・高尾の新しい家事代行（架空の店）。手入れの行き届いた家、杉と山の緑、朝の光
- 読者：高齢の利用者本人と、代わりに予約する30〜50代の家族
- 主な役割：「担当を選ぶ→空きを選ぶ→払う」をスマホで迷わず試せること。見た目で契約を取る

## 定番に寄っていないかの照合（PLAN のデザイン計画）
| よくある型 | 計画 | 判定 |
|---|---|---|
| クリーム地＋高コントラスト明朝＋テラコッタ | 白地＋杉緑、黄土は選択中の枠だけ | 回避。ただし「明朝＋深緑」は和モダン・介護系の定番なので、**黄土を外す案との比較（PLAN 46行）を批評ループ1回目で必ず行う** |
| 黒地＋蛍光1色 | 該当なし | 回避 |
| 新聞風の罫と段組 | 区切りは余白と罫1本 | 罫を増やさないこと |
| SaaS カード一式 | 行を積む・影なし・角丸2段階 | 回避。スタッフの「色面＋名前」が角丸の箱3つ並びに見えないよう、色面は行の左端の帯にとどめる |
| 英大文字ラベル・中黒・「→」・等幅の小ラベル | 禁止済み | 実装後に grep で確認（`·`・`→`・`text-transform: uppercase`・`monospace`） |
| ヒーローの大きな数字＋小ラベル | ヒーローは**実データの○×表** | 主題に固有。ここに大胆さを1点だけ使う |

## 1点に集中させる物
トップ最初の画面の ○×縮小表（駅・病院の空席表の文法）。周りの見出し・写真・ボタンは静かにする。写真（`tatami-light.webp`）は PC の右側だけで、○×より目立たせない。

## 批評ループで見ること
- 390×844：最初の画面に見出し・○×表・主ボタンが収まるか。「大きく」でも横スクロールなし
- 1440：左の行長が35〜40字以内か、写真が○×より強くないか
- 他の家事代行・介護サイトと並べて見分けがつくか → 装飾を1つ外す
- 文言：起きることをそのまま書く。「お任せください」などの売り文句、一語だけの色替えを入れない
