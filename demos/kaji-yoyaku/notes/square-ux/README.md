# Square 予約サイトの手本（実測）

対象: https://book.squareup.com/appointments/yty8z30rub8b6y/location/L54G6PFCMRTWP （架空の店「高尾の家事手伝い みどり」）
撮影日: 2026-10-23。script は `capture.mjs`（`DAY=10 node capture.mjs 390` / `DAY=11 node capture.mjs 1440`、tests の playwright を使う）。
生の値は `styles-390.json` `styles-1440.json`（computed style）、文言と操作部品は `dump-*.txt`、実行記録は `log-*.txt`。
png は `NN-名前-390.png`（最初の画面）、`-390-full.png`（内容の高さまで窓を伸ばした全体）、`-bottom.png`（内側を最下部まで送った画面）。1440 も同じ。

## 流れ（画面数 = 6 種 x 2 サイズ）
1 サービス一覧 → 2 サービス詳細＋スタッフ選択（同じ画面）→ 3 「さらに予約を追加しますか？」→ 4 日時（週の帯、月に展開できる）→ 5 時刻を選ぶ → 6 お会計（お客様情報）。
画面の対応: 01-services / 02-staff（選択前）/ 03-staff-picked（指名なし選択後）/ 04-addmore / 05-calendar-week / 06-calendar-month / 07-calendar-nov / 08-times / 09-checkout。
時刻のボタンを押すと、確認の画面なしでそのまま 6 のお会計に進む。ページ遷移は URL が `/services` → `/services/{id}` → `/services`（追加後）→ `/availability` → `/checkout`。

## 共通
- ヘッダー: 左に店名「高尾の家事手伝い みどり」（19px/700、黒）、右にハンバーガー（メニュー）。戻るボタン・進捗表示（ステップ数）は無い。スマホ幅 390 は左右余白 16px。
- フォント: "Square Sans Display VF", "Square Sans Display", Helvetica, Arial, sans-serif（日本語は OS 側の代替）。サイズは 12 / 14 / 16 / 19 / 25px、太さ 400 / 500 / 600 / 700。
- 色: 背景 #ffffff、本文 rgba(0,0,0,.9)（約 #1a1a1a）、補助文字 rgba(0,0,0,.55)（説明）と #737373（注記・曜日・担当）、主ボタンと「ログイン」「その他」リンクと選択中ラジオ #1e4a3a（濃い緑）で白文字、仕切り線 rgba(0,0,0,.05)、薄い灰の面 rgba(0,0,0,.05)（約 #f2f2f2）、円形ボタン #f3f4f6。
- 角丸: ボタン・入力・時刻・日付 6px、カード 6px、展開ボタン 9999px（円）、スマホの下部カートの上端 24px。
- 主ボタン: 高さ 48px（日時画面の「利用可能な予約日時へ」だけ 40px・14px/600）、幅いっぱい、16px/600、padding 12px 16px。
- 下部に「Square 提供」ロゴ＋下線リンク「クッキーの詳細設定」（#737373）。
- cookie: OneTrust のバナーが出る。「すべて拒否する」を押して進めた（非必須を断った）。通信先に Sentry・Datadog・OneTrust 等が見えた（拒否後も Sentry は出ている。未確認）。

## 1 サービス一覧（01-services）
- 文言: 「家事代行 2時間」「家事代行 3時間」「家事代行 4時間」。各行に説明「掃除機がけ、台所と水まわり、お部屋の片づけ。ご自宅にお伺いします（1時間3,500円）。」、続けて「￥7,000 ・ 2時間」「￥10,500 ・ 3時間」「￥14,000 ・ 4時間」。ページ見出し「サービス」は画面上は非表示（1x1px、読み上げ用）。
- 並び: 名前（16px/500、黒）→ 説明（14px/400、行間 22px、灰 55%）→ 価格・時間（14px、#1a1a1a）。行は仕切り線で区切る一覧。カードではなく写真も無い。行全体が押せる。
- スマホ/PC: 同じ作りで、PC は中央 608px の列（左右に大きな余白）。説明は PC なら 1 行に収まる。

## 2 サービス詳細＋スタッフ（02-staff、03-staff-picked）
- 文言: パンくず「すべてのサービス / 家事代行 2時間」→ 見出し「家事代行 2時間」（約 25px/700）→「￥7,000 ・ 2時間」→ 説明 → 見出し「スタッフ」（19px/700）→ 選択肢 → 主ボタン「追加」。
- スタッフの選択肢（ラジオ）: 「指名なし」（人 3 人のアイコン）、「小林 和美」「山本 さち子」「森田 恵」（人 1 人のアイコン）。各人に紹介文（14px、灰、2 行で省略）と「その他」（緑・太字の下線リンク、14px/600）。丸い円（約 58px、灰緑 #e2e6e4 の面）に線のアイコン。写真は無くアイコンのみ。
- スマホ: 「指名なし」は最初から選択済み（緑の丸に白点）。「追加」は画面下に固定（上に細い線）。PC: 画像では未選択で表示された（クリックで選択）。「追加」は一覧の下に置かれ固定ではない。PC は 608px の列。
- 行は仕切り線で区切る一覧。ラジオは右端、選択中は #1e4a3a。

## 3 さらに予約を追加しますか？（04-addmore）
- 文言: 見出し「さらに予約を追加しますか？」、サービス一覧が再表示され、選んだ行に「追加済み」（14px/600、灰）。下部に「家事代行 2時間 / 担当：すべてのスタッフ / ￥7,000」と主ボタン「次へ」（スマホ 64px 幅の小さなボタン、PC 352px）。
- スマホは画面下に固定のカート（白、上端の角丸 24px、影）。

## 4 日時: 週の帯（05-calendar-week）と月表示（06, 07）
- 文言: 「2026年10月」（25px/700）、前後の矢印（「先週」「来週」、40x40、角丸 6px、灰 5% 面、先頭は無効で文字 30%）、曜日「日 月 火 水 木 金 土」（14px、#737373）、日付、展開ボタン（円、シェブロン、aria「展開して月表示を表示」）、注記「時刻はJSTで表示されます。」（JST だけ緑）、見出し「今日、2026年10月23日金曜日」（19px/700）、案内「次に予約可能な日は10月24日土曜日です。」、主ボタン「利用可能な予約日時へ」。
- カレンダー: 初期は 1 週間の帯。今日は黒 (#000) の角丸 6px・白文字（600）。空きの無い日（過去日）は取り消し線＋灰文字（#737373）。空き日は黒。展開すると月表示（日曜始まりの 7 列、日付 16px、行の高さ約 48px、月見出しは中央、矢印は「Previous month」「Next month」）。月表示の空き無し日は #9ca3af＋取り消し線、選択中は rgba(0,0,0,.9) の面に白文字、角丸 6px、約 40px 四方。月の最終週を超えた空欄は無し。
- 日付を押すと同じ画面の下に時刻が出る（画面遷移なし）。選んだ日が今日のように空きが無い時は案内文と主ボタンが出る。
- スマホ: 下部固定のカート（「家事代行 2時間 / 担当：すべてのスタッフ / ￥7,000 / 鉛筆」）。PC: 左 608px にカレンダー、右 352px に「予約のサマリー」カード（枠 1px、角丸 6px、価格と鉛筆）。左右の列の間は 32px。
- 注意: 今回は 11 月の平日（10 日火曜、11 日水曜、12 日木曜）を選んだ。月曜〜日曜で空きの有無が変わるかは全日確認していない。

## 5 時刻（08-times）
- 文言: 見出し「2026年11月10日火曜日」（19px/700）、区分ラベル「午前」「午後」「夜間」（14px/500）、時刻ボタン、空きの無い区分は「予約可能な時間がありません」（16px、#737373）。
- 刻み: 30 分（9:00, 9:30, … 14:30 の開始時刻。2 時間枠の最終開始が 14:30）。表記は 24 時間の「9:00」「12:30」（先頭 0 無し、「午前/午後」の文字は付かない）。区分は午前（〜11:59）、午後（12:00〜）、夜間（空き無しでは文言のみ）。
- ボタン: 面 rgba(0,0,0,.05)（約 #f2f2f2）、文字黒の 14px/600、角丸 6px、高さ 40px。スマホは 3 列（幅 96px、間隔 約 8px）、PC は 4 列（幅 144px）。選択前の「選択中」表示は無く、押すとすぐお会計へ進む。
- 備考: 空きは固定ではない。私の確認で「予約する」前の 10 分間の確保（hold）を何度か作り、その間は同じ時間帯が減った（例: 9:00〜12:00 が消えて 12:30〜14:30 だけになった）。確保は予約確定ではなく、10 分で失効する。

## 6 お会計（お客様情報）（09-checkout、-bottom、-full）
- 文言（上から）: 「お会計」（19px/700、中央）、「予約が10分間確保されます」（14px、#737373、中央）、予約カード「11月10日火曜日 / 12:30 – 14:30 / 予約当日のお支払い：￥7,000」（カレンダーのアイコン、右に展開の円ボタン）、「連絡先情報」（19px/700）と右に「ログイン」（緑、下線）、国コード「JP +81」、「電話番号」、SMS 同意の注記（12px、省略＋「さらに詳しく」）、「姓」「名」「メール」、見出し「この予約はどこで実施されますか？」、「住所をご入力いただければ、スタッフがご指定の場所に伺います。」、「000-0000（半角）」「都道府県」（選択式）「市区町村」「住所１（丁目・番地）」「住所２（建物名・部屋番号）」、「予約に関するメモ」と右に「追加」、「キャンセルポリシー」、本文「予約開始前にキャンセルまたはスケジュール変更を行ってください。」＋「すべてのポリシーを見る」、注記「予約すると、Square 予約でアカウントが自動的に作成されます。アカウントには、携帯電話番号を使っていつでもログインできます。また、Squareからプロモーションメールが届く場合があります。」（12px 程度）、主ボタン「予約する」（#1e4a3a、白文字、48px、角丸 6px）。入力も送信もしていない（予約する は押していない）。
- 入力欄（market-input-text）: 高さ 64px、幅いっぱい、角丸 6px、白背景、内側 16px、ラベルは入力欄内のプレースホルダ（16px、黒 55%）で、入力すると上に小さく浮く作り（未確認）。枠線の色は shadow 内で取得できず、画像では薄い灰（約 #d0d0d0）。フォーカス中は緑 (#1e4a3a) の枠（メール欄が自動でフォーカスされていた）。姓・名は横に 2 列、他は 1 列、電話は国コードと横並び。
- スマホ: 予約カードは折りたたみ（シェブロン）、「予約する」はページ最下部（固定ではない）。PC: 左 608px にフォーム、右 352px に「予約のサマリー」（カードは展開済み: 日時、「家事代行 2時間 ￥7,000」、「小計」「外税」「合計」、「本日のお支払い ￥0」「予約当日のお支払い ￥7,000」）と「予約する」ボタン。SMS 注記は PC では全文表示。
- 「キャンセルポリシー」の本文は 16px、リンクは太字（600）。区切りは薄い線。

## 失敗・未確認
- 枠線の色、フォーカス以外の入力欄の状態、入力後のラベル、エラー表示、ログイン／国コードのメニューは未確認（入力しない規則のため）。
- 週の帯の矢印、展開の動き（アニメーション）、画面遷移の動きは静止画のため未確認。
- 色の rgba は白背景上の見た目として #1a1a1a / #8c8c8c / #f2f2f2 に近い。getComputedStyle の生の値は styles-*.json。
- shadow DOM 内（market-button の内側）の背景は透明で、主ボタンの緑は外側の host の背景（予約する）から得た。「追加」「次へ」「利用可能な予約日時へ」の host の背景は透明と出たが、画像では同じ緑 #1e4a3a。
- 390 と 1440 で日付が違う（390 は 11/10、1440 は 11/11）。確保が互いを塞がないようにするため。
- 1440 の第 2 画面（02-staff）は選択前に見え、スマホは最初から選択済みに見える。差かタイミングかは未確定。
- networkidle は Square のスクリプトで終わらないため domcontentloaded＋待ちを使った。
