# 書体の調査（2026-10-22）

基準：読みやすさを満たす書体の中から、採用の実績・普及・公的な指針で選ぶ（主観で順位を付けない）。1書体、明朝なし。

## 推奨：Noto Sans JP（本文400、ボタン500、見出し700）
- デジタル庁デザインシステムが本文の書体に指定（理由「可読性や視認性が高い」、本文16px以上、行の高さ1.5倍以上）https://design.digital.go.jp/dads/foundations/typography/
- 約27サイトを確かめた中で、Web フォントの採用が最も多い（7件）。デジタル庁、東京都、ベアーズ、くらしのマーケット、ニチイ学館、freee、Airリザーブ（欧文だけ）。Google Fonts の人気順は全1,950書体中10位
- 100〜900 の可変フォント。1書体で太さの段を作れる

## 次点：BIZ UDPGothic（今の書体）
- UD 書体の可読性研究がある（モリサワと慶應の中野泰志教授の共同研究）https://www.morisawa.co.jp/fonts/udfont/study/ 。ただし BIZ UD そのものの結果の数値は公開されていない
- 政府広報オンラインが採用。デジタル庁は代わりの書体の欄に書くだけ。Google Fonts の人気順は160位
- 太さは400と700の2段だけ

## 確かめられなかった事
- Noto と BIZ UDP を高齢者で直接比べた試験は見つからない。モリサワの研究報告の数値は原文で未確認
- 採用の数は手で選んだ約27サイトで、統計ではない。デザイン賞の受賞サイトは未調査
