# サイト内の予約ページの仕様（book.html）

決定（2026-10-23、利用者）：予約から支払いまでをひと続きで試せるよう、サイトの中に予約の画面を作る。見た目は本番の Square 予約にできる限り近づける。空き時間はデモ用に作った物。カード払いは Stripe のテスト用の支払い画面。Square の審査は通さない。

手本：本物の Square 予約の画面 `notes/square-ux/`（README と png）。見た目の決まりは下の「見た目」に書く。

## 流れ（Square 予約と同じ段の切り方）
```
サイトの「予約する」 → book.html
  service  サービス一覧     家事代行 2時間 / 3時間 / 4時間（行を押すと次へ）
  staff    サービス詳細＋スタッフ  パンくず・見出し・価格・説明・「スタッフ」：指名なし ＋ 3名（ラジオ）→「次へ」
  time     日時            週の帯（月表示に広げられる）→ 日付の見出し → 午前／午後／夜間の時刻ボタン（押すとすぐ次へ）
  checkout お会計          予約カード・連絡先情報・場所・メモ・キャンセルポリシー・テスト用カードの注記 →「お支払いへ進む（テスト）」
  → Stripe のテスト用の支払い画面（コースの時間ごとのリンク。同じタブ）
  → book.html?paid=1
  done     完了            「予約が確定しました」＋内容
```
- Square の「さらに予約を追加しますか？」の段は省く（1回に1件だけ）。
- 段は URL の `?step=service|staff|time|checkout|done` で表し、`history.pushState` で積む。ブラウザの戻るで前の段に戻る（`popstate`）。選んだ内容は残る。
- 入口の引数：`book.html?staff=s1`（スタッフ紹介の各「予約する」）。担当を選んだ状態で始める（staff の段ではその人のラジオが選ばれている）。不正な値は無視する。
- 前の段が済んでいない段を URL で直接開いたら、最初の済んでいない段を出す。
- staff の段の初期は「指名なし」が選ばれている（`?staff=` があればその人）。
- 選んだ内容は、スマホでは画面下の固定のカート（「家事代行 2時間 / 担当：すべてのスタッフ / ￥7,000」と編集の鉛筆）、PC では右の列の「予約のサマリー」に出す（time と checkout の段）。鉛筆／サマリーの編集で service の段に戻る。

## 空き時間（デモ用の作り物。純粋関数 js/slots.js）
- スタッフの勤務は Square の設定と同じ。content.js の STAFF に機械用の値を足す：
  山本 `workDays [1,2,3,5]` 9〜17時、小林 `[0,2,4,6]` 9〜15時、森田 `[1,3,4,5,6]` 10〜17時（0=日）。
- 開始時刻は30分刻み。終わり（開始＋コースの時間）が勤務の終わり以下の時だけ選べる。
- 選べる日は、明日から 60 日先まで（今日は選べない）。
- 埋まっている予約（作り物）：`fakeBusy(staffId, date)` が日付と担当から決まった形で返す（乱数は使わず、同じ日はいつ見ても同じ）。1日に0〜2件、各2〜3時間。重なる開始時刻は選べない。
- このデモで確定した予約は `localStorage` の `kajiDemo.bookings` に足し、その時間も埋まりとして扱う（もう一度予約すると、その時刻は出ない）。
- 指名なし：その時刻に空いているスタッフが1人でもいれば選べる。確定の時に、空いている人のうち STAFF の並びで最初の人を担当にする。
- 空きが1つも無い日は選べない見た目にする（Square の見せ方に合わせる）。
- 関数の形（すべて純粋、`now` は引数）：
  - `workRange(staff, date)` → `{ start, end }`（分）か `null`（お休み）
  - `fakeBusy(staffId, date)` → `[{ start, end }]`（分）
  - `openTimes({ staff, date, minutes, booked, now })` → 開始時刻（分）の配列。`booked` は `[{ staffId, date, start, end }]`
  - `openTimesAny({ staffList, date, minutes, booked, now })` → `[{ start, staffIds: [...] }]`
  - `bookableDates(now, days = 60)` → `"YYYY-MM-DD"` の配列
  - 時刻の表示は「9:00」「13:30」の形（Square と同じ。24時間、先頭の0なし）。区分は午前（〜11:59）・午後（12:00〜17:59）・夜間（18:00〜）。空きの無い区分は「予約可能な時間がありません」

## お会計（checkout の段。Square のお会計と同じ並び）
上から：見出し「お会計」→ 予約カード（日付「11月11日水曜日」、「9:00 – 11:00」、「家事代行 2時間」「担当：山本 さち子」または「担当：すべてのスタッフ」、金額）→ 「連絡先情報」：電話番号（「JP +81」の表示つき）・姓・名・メール →「この予約はどこで実施されますか？」「住所をご入力いただければ、スタッフがご指定の場所に伺います。」：郵便番号（000-0000（半角））・都道府県（選択。初期は東京都）・市区町村・住所１（丁目・番地）・住所２（建物名・部屋番号、任意）→「予約に関するメモ」（任意、押すと開く）→「キャンセルポリシー」（Square の取り消し規定と同じ内容。デモの注記を含む）→ 注記「架空の店のデモです。見本の内容で構いません。カードはテスト用の番号 4242 4242 4242 4242、先の月年、任意の3桁で払えます。実際の請求はありません」→ 主ボタン「お支払いへ進む（テスト）」。
- PC は左にフォーム、右に「予約のサマリー」（日時・サービスと担当・小計・合計）と主ボタン。
- 必須：電話番号、姓、名、メール、郵便番号、都道府県、市区町村、住所１。誤りは欄の下に赤字（例「電話番号を入力してください」）。最初の誤りの欄にフォーカスを移す。どこにも送らない。
- Square の SMS の同意文・「ログイン」・アカウント自動作成の注記は出さない（Square の画面の文なので、デモでは載せない）。
- 押すと、入れた内容と選んだ内容を `sessionStorage` の `kajiDemo.pending` に置き、`CONFIG.payment.links[時間]` へ同じタブで移る。リンクが空なら「準備中」のモーダル。サーバーにもURLにも個人の情報を出さない。

## 完了（book.html?paid=1）
- pending があれば：担当（指名なしなら空いている最初の人）を決めて `kajiDemo.bookings` に足し、pending を消し、URL を `?step=done` に置き換え、「予約が確定しました」、内容（日時・サービス・担当・お伺い先・お支払い済みの金額）、注記「本番では、予約の内容を書いたメールが届きます」、「トップへ戻る」。
- pending が無い（再読み込み・別のタブ）：最後に確定した予約を出す。それも無ければ「予約の情報が見つかりません」と「最初から予約する」。

## 設定（js/config.js）
```js
booking: {
  page: "book.html",       // サイトの「予約する」の行き先
  square: "https://book.squareup.com/...", // 本物の Square 予約（架空の店）。book.html の下に小さなリンクで残す
},
payment: { links: { 2: "https://buy.stripe.com/test_9B67sK0u2cEA5HV3Yd2go00", 3: "https://buy.stripe.com/test_aFa00igt0cEAdan8et2go01", 4: "https://buy.stripe.com/test_4gM8wOfoW1ZW7Q3fGV2go02" } },
```
Stripe の3つのリンクの戻り先は `https://kaji-yoyaku-demo.pages.dev/book?paid=1`（設定済み）。手元では戻り先が公開サイトになる点に注意（手元の試験は Stripe へ移る直前までと、`?paid=1` を直接開く形で行う）。

## サイト側の変更
- `[data-book="any"]` → `book.html`、`[data-book="s1"]` → `book.html?staff=s1`。準備中のモーダルは消す。
- payment.html と、その導線（`[data-pay-link]`、トップの `data-pay-test-link`）を消す。`hasPaymentTest`・`wirePaymentLinks`・`mountPayment` も消す。
- 文言：「予約は Square 予約の画面で行います」「Square 予約の画面で…」「担当は予約の画面で選べます」を、新しい流れに合わせて直す（レビュー役に見た目ごと通す）。

## 見た目
手本：`notes/square-ux/` の png（02-staff-390、05〜08 の日時、09-checkout）と README の数値。**Square の見た目の決まりに合わせ、Square の名前・ロゴ・「Square 提供」の表示・SMS 同意などの Square 固有の文は使わない**（お店の予約の画面として作る）。
- 書体は Noto Sans JP（サイトと同じ。Square の書体は使えない）。数字は `font-feature-settings: "tnum"`。
- 色（css/book.css の :root で定義。サイトの tokens.css は読み込んでよい）：背景 #fff、本文 rgba(0,0,0,.9)、補助 #737373、説明 rgba(0,0,0,.55)、主の色 #1e4a3a（主ボタン・選択中のラジオ・リンク）、面 rgba(0,0,0,.05)、線 rgba(0,0,0,.05)〜.1、アイコンの円 #e2e6e4、選択中の日 rgba(0,0,0,.9) に白、空きの無い日 #9ca3af に取り消し線、誤り #c62828。
- 角丸は 6px（ボタン・欄・日付・時刻・カード）。円の物（アイコン・展開ボタン）だけ丸。影は付けない（スマホの下のカートの上だけ薄い影）。
- ヘッダー：左に店名（19px/700、押すとトップ）、右は無し（Square のハンバーガーの代わりに何も置かない）。戻るボタン・何段目かの表示は無い（Square と同じ）。ブラウザの戻るは効く。staff の段にはパンくず「すべてのサービス / 家事代行 2時間」（前半が戻るリンク）。
- service の段：区切り線で分けた一覧。行ごとに名前（16px/600）、説明（14px、補助色、2行まで）、「￥7,000 ・ 2時間」。写真もカードも無し。
- staff の段：見出し（25px/700）、「￥7,000 ・ 2時間」、説明、「スタッフ」（19px/700）、選択肢の行（左に約58pxの丸、右端にラジオ）。指名なしは人3人の線のアイコン。3名は丸の中に写真（assets/staff-*.webp。本番は Square にスタッフの写真を上げる）。名前（16px）と紹介（14px、補助色、2行で省略）。主ボタン「次へ」はスマホでは画面下に固定（上に細い線）、PC は一覧の下。
- time の段：月の見出し（25px/700、中央）と前後の矢印（40×40の角丸の面、選べない側は薄く）。初期は1週間の帯（日〜土）、下の丸いシェブロンで月表示に広げる。曜日は14px補助色。その下に「時刻はJSTで表示されます。」は出さない（日本の店なので不要）。日付の見出し「2026年11月12日木曜日」（19px/700）、区分ラベル（14px/500）、時刻ボタン（面 rgba(0,0,0,.05)、14px/600、高さ 44px、角丸 6px、スマホ3列・PC4列、間 8px）。押すとすぐ checkout。最初は、選べる最初の日を選んだ状態で開く。
- checkout の段：見出し「お会計」中央 19px/700。欄は高さ 56px以上、角丸 6px、枠 1px rgba(0,0,0,.15)、フォーカスで主の色の枠。ラベルは欄の中の placeholder ではなく、欄の上に小さく出す（入れた後も何の欄か分かるように。Square との違いはこれだけ）。主ボタンは高さ 48px、幅いっぱい、16px/600、白文字。
- 列：スマホは左右 16px の余白で1列。PC（≥960px）は中央に 608px の主の列 ＋ 32px ＋ 352px のサマリーの列（time と checkout）。service と staff は 608px の1列。
- 動き：段の切り替えは、それまでの位置に関係なくページの上へ戻す。動きの演出は付けない（Square と同じ）。
- 下：デモ帯（`mountDemoBand`、サイトと同じ「ご提案用のデモです。実際の請求はありません」）。ページの一番下に小さく「本番の予約は Square 予約で受け付けます。」と、`[data-square-link]`「Square 予約の画面（架空の店）を見る」。
- 横スクロールなし（390・1440）。タップの高さ 44px 以上。文字 14px 未満は使わない（注記も 14px）。


## data 属性（試験の足場）
`[data-step="service|staff|time|checkout|done"]`（今の段の入れ物。1つだけ見える）、`[data-service-option="2|3|4"]`、`[data-staff-option="any|s1|s2|s3"]`、`[data-date="YYYY-MM-DD"]`（選べない日は `aria-disabled="true"`）、`[data-time="HH:MM"]`、`[data-summary]`（カート／サマリー）、`[data-edit]`（鉛筆）、`[data-breadcrumb-back]`、`[data-next]`（staff の「次へ」）、`[data-week-prev]`・`[data-week-next]`・`[data-expand-month]`、`[data-field="phone|lastName|firstName|email|zip|pref|city|address1|address2|note"]`、`[data-error]`、`[data-pay]`、`[data-done-summary]`、`[data-square-link]`。
