## Context
クラウドワークスの案件（応募155人、先方は前向き）。制作費は税込33,000円。本番は **WordPress ＋ Square 予約（プラス）**。10/24（土）までに、スマホで「スタッフを選ぶ → 空き時間を選ぶ → 決済」を試せるデモの URL を送ると約束済み。

## 方針（今有効）
- **予約が主役**：予約〜決済は Square 予約の実物（架空の店のアカウント）で見せる。自作の予約エンジンは作らない
- サイトは本番の WordPress の見本（7ページ）。トップとスタッフ紹介だけ丁寧に作り、ほかはある程度の完成度でよい
- 仕様：`docs/spec-site.md`。決定：`docs/decisions.md`。予約システムの調査：`notes/booking-systems.md`・`notes/square-check.md`、設定手順：`notes/square-setup.md`
- 書体は Noto Sans JP の1種類。個性はレイアウト・写真・色・余白で出す
- 守ること：制作者の連絡先を出さない、デモ注記を常時表示、noindex、検索順位の保証や未確認の事実（保険など）を断定しない

## 作業手順
0. 片づけ（済）
1. Square 予約の確認（審査前の公開・決済のテスト・担当ごとの URL）→ 利用者がアカウントを作り、店とスタッフ3名を登録
2. 仕様 `docs/spec-site.md`（済）→ e2e の試験を先に → 実装（入口のページ → ほかの5ページ・削除）
3. 批評ループ2回 → 独立レビュー2本（高齢者・家族。サイトから Square で予約し終えるまで）
4. README（公開の手順、Square の設定、WordPress への対応表、写真の出典）
5. 送る文面の案（URL、試し方、本番で変わる所、税込33,000円への訂正、費用の内訳）
6. push・Cloudflare Pages の公開・送信は、それぞれ別に承認を取る
